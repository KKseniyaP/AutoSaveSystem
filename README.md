# AutoSaveSystem - Универсальная система сохранений для Unity

Система автоматического сохранения для Unity с поддержкой чекпоинтов, ручного сохранения, отображения прогресса и восстановления после переворота робота.

---

## Возможности

- Автоматическое сохранение при прохождении чекпоинтов
- Ручное сохранение и загрузка по кнопке
- Отображение последней позиции и заряда батареи на экране
- Восстановление позиции при перевороте робота
- Экстренное сохранение при закрытии приложения
- Сохранение в JSON файл
- Поддержка интерфейса ISaveable (легко расширяется под любые объекты)

## Установка и использование

1. Склонируйте репозиторий и откройте проект в Unity 6.0 LTS
2. Добавьте на сцену объект SaveManager (пустой GameObject с компонентом SaveManager)
3. Добавьте на сцену объект RespawnManager для отслеживания переворота
4. Настройте робота:
   - Добавьте компонент RobotState
   - Установите тег "Player"
   - Добавьте Rigidbody и коллайдер
5. Разместите на сцене префаб CheckpointZone
6. Запустите игру и протестируйте

---

## Управление

- Прохождение чекпоинта - автоматическое сохранение
- Кнопка "Сохранить игру" на UI - ручное сохранение
- F5 - ручное сохранение (альтернатива)
- F9 - ручная загрузка последнего сохранения
- Переворот робота - автоматическая загрузка и телепортация
